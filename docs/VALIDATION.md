# 发布前验证

本源码发布包在2026-10-21完成以下本地检查：

- 在全新、固定提交的官方AppleALC工作副本上应用补丁并安装layout16资源成功。
- 在独立私有测试目录生成参考机参数和经哈希验证的固件头文件；两组参数均未写入公开仓库。
- 使用仓库提供的构建脚本，全新编译CirrusAudioFixup与AppleALC均成功；未将重建产物安装到机器EFI。
- 主机测试通过：高音跟随状态机、输出写入策略、实际停止播放代码提取。完整旧runtime mock不在通过项内。
- 公开文件中未发现参考机功放UID、机器序列号/UUID、本地个人路径、EFI快照或固件二进制。

本地构建成功不能证明在另一台同型号机器上安全或有效。参数化发布源码尚无第二台机器实测；最终高音跟随版本仅有用户音乐正常的反馈，睡眠、耳机和长时间播放仍需独立验证。首次版本以源码/复现文档为主，不提供通用预编译驱动。
