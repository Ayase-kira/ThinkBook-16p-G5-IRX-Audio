# 适配边界

当前参考硬件：ThinkBook 16p G5 IRX，ALC287 10EC:0287 / SSID17AA:38F9，CS35L41 B2，CSC3551，I2C4，左0x41、右0x40，外部VSPK/GPIO1开关。与部分Legion机型的左右顺序和升压拓扑不同。

型号相同不代表功放、喇叭批次及调音相同。不要把38FA、其他代ThinkBook、其他CS35L系列或内部升压配置当成本方案已验证对象。

源码使用每台机器单独生成的MachineIdentity.hpp，保留“硬件UID等于本机EFI校准目标UID”的检查；高音跟随另外匹配本机两颗功放遥测中的电阻校准和地址。这不是取消校准门槛，缺少有效出厂记录不能以编造数据代替。示例配置不包含可用UID/电阻值。

发布版参数化源码未在第二台机器验证；本机成功配置的驱动仍保持不变，本仓库的发布准备没有再次修改机器EFI。欢迎先提交脱敏兼容性信息，再开展独立适配。
