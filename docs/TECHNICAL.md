# 技术过程

低音恢复的关键试验将播放数字音量从0xBA00(-24dB)调整为0x8000，并把增益从0变为上游默认编码0x233；两项同时改变，因此不能断言其中某项是唯一原因。停止播放仍使用静音0xA678和增益0。固件上传保持60字节分块，校准来自本机EFI。

低音正常的ALC287路径为Pin17→DAC2(0x02)，耳机Pin21→DAC3(0x03)。Pin14仅连接DAC2；临时将其D0、输出0x40、模拟增益0后，高音实听正常。

失败试验：把Pin14作为另一个并行输出加入PathMap时，AppleHDA实际产生format0x33、stream0x12；低音驱动未识别有效立体声而维持静音。回退后恢复format0x31、stream0x10。不能仅凭资源文件有两条路径就宣称四扬声器成功。

最终方案保留原PathMap，在AppleALC现有executeVerb钩子完成原始状态命令后核对双声道/功放身份/耳机状态，只操作Pin14既有开关与静音。仅允许实测通过的format0x31、channel0。自己未接管的Pin14不强行覆盖。故障时回退并锁定。具体实现见applealc/。

分频试听曾用同一音源的1kHz Linkwitz–Riley四阶低通、高通及全频对比；只证明可听频谱有区别，不是把两个频段独立送进两组扬声器，也不是测得原厂分频点。没有修改DSP调音。
